# M-Paspor & MILES Process Analysis

A Business Analysis case study documenting the Indonesian passport application process (M-Paspor) and the Mobile Immigration Services (MILES). 

## What is inside
- `docs/SOURCES.md`: Every source used, with the date opened.
- `docs/facts.md`: The baseline facts extracted from official SOPs.
- `docs/pain-points.md`: Friction points identified in the current process.
- `diagrams/`: As-Is and To-Be process flowcharts (swimlanes).

## How to check my work
Every claim or fact is tagged with a source ID and page number. Any item that is my own deduction rather than explicit text from a source is labeled **Assumption**.
